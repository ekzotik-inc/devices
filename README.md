# CRM Device Generator

Современное веб-приложение для **генерации устройств** под импорт в CRM.
Пользователь загружает только эталонный CSV-шаблон CRM, а приложение по его
структуре генерирует N случайных устройств (10 / 50 / 100 или произвольно) и
формирует готовый CSV, **на 100% совместимый по структуре с шаблоном**.

## Главное правило проекта

CSV **никогда не генерируется «по памяти»**. Структура итогового файла
полностью определяется загруженным шаблоном:

- те же названия колонок;
- тот же порядок колонок;
- тот же разделитель полей;
- та же кодировка (UTF-8, с BOM или без — как в шаблоне);
- то же расширение файла;
- тот же перенос строк (CRLF/LF);
- то же экранирование кавычками.

Если структура шаблона меняется — приложение автоматически определяет новую
структуру и использует именно её.

## Правила генерации (значения по умолчанию)

| Колонка | Значение |
| --- | --- |
| `market_code` | всегда `UZ04` |
| `stock` | всегда `1` |
| `master_allocation_warehouse_id` | всегда `1` |
| `packing_date` | дата загрузки файла (в формате шаблона) |
| `KIT_ILUMA_I_ONE_code` | пусто |
| `holder_code` | пусто |
| `*_codentify` | случайный уникальный код (Codentify, 12 символов) |
| `*_description` | редактируемое значение (по умолчанию название продукта) |

Каждое правило **редактируется в интерфейсе**. Доступные стратегии для любой
колонки: пусто, фиксированное значение, дата генерации, случайный код
(Codentify), случайное число, случайный выбор из списка, порядковый номер.

## Возможности

- **Drag & Drop** загрузка шаблона CRM (CSV).
- **Анализ структуры** шаблона: колонки, порядок, разделитель, перенос строк,
  BOM, формат даты.
- **Гибкие правила генерации** по каждой колонке с разумными дефолтами.
- **Полная валидация**: количество строк, дубли кодов (codentify), пустые
  значения там, где по правилу должно быть заполнено, неверный формат
  `packing_date`, лишние пробелы. Понятные сообщения и скачиваемый отчёт.
- **Предпросмотр** итоговой таблицы с поиском, сортировкой, фильтрацией,
  пагинацией и счётчиком записей — видно именно то, что будет выгружено.
- **Экспорт** CSV строго по структуре шаблона.
- **UX**: индикатор генерации, уведомления, журнал ошибок.
- Адаптивная вёрстка в фирменном минималистичном стиле IQOS.

## Архитектура (модули)

`src/modules/`:

| Модуль | Назначение |
| --- | --- |
| `fileLoader.ts` | чтение шаблона как текста (UTF-8) |
| `structureAnalyzer.ts` | анализ структуры шаблона |
| `deviceGenerator.ts` | правила по умолчанию и генерация устройств |
| `validator.ts` | проверка сгенерированных данных |
| `csvExporter.ts` | экспорт CSV строго по шаблону + отчёт об ошибках |
| `types.ts` | общие типы |

UI: `src/components/` (DropZone, StructureCard, RulesPanel, ValidationPanel,
PreviewTable, Toast).

## Запуск

```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Деплой (GitHub Pages)

Workflow `.github/workflows/deploy.yml` при пуше в рабочую ветку (или `main`)
собирает приложение и публикует его на GitHub Pages:
**https://ekzotik-inc.github.io/devices/**

Источник Pages включается один раз вручную:
`Settings → Pages → Build and deployment → Source = «GitHub Actions»`.
